# Neocarts для OpenCart

[English](README.md) · **Українська**

Плагін додає в магазин на OpenCart підписки на товари від [Neocarts](https://neocarts.com).
Покупець може оформити підписку на корм, каву чи косметику, і замовлення приходитиме йому
автоматично: раз на тиждень, на місяць чи з будь-якою іншою частотою. Оплату, повторні
списання й листи покупцям бере на себе Neocarts. Кожне оплачене замовлення, і перше, і кожне
наступне, з'являється у вашій адмінці OpenCart як звичайне замовлення.

Повна документація: [docs.neocarts.com](https://docs.neocarts.com/plugins/opencart/overview/).
Питання — на support@neocarts.com.

## Версії OpenCart

| OpenCart | Який файл завантажувати | PHP |
| --- | --- | --- |
| 2.3 | `neocarts-oc2-X.Y.Z.ocmod.zip` | від 7.1 |
| 3.0 | `neocarts-oc3-X.Y.Z.ocmod.zip` | від 7.1 |
| 4.x | `neocarts.ocmod.zip` — не перейменовуйте його | від 8.0 |

Файли лежать у розділі [Releases](https://github.com/neocarts/opencart-plugin/releases/latest).
Ми перевіряємо плагін на версіях 2.3.0.2, 3.0.5.1 і 4.1.0.4.

## Як встановити

1. **Завантажте файл в адмінку.** В OpenCart 3.0 і 4.x — через інсталятор розширень (у 4.x
   після завантаження натисніть ще й «Встановити»). Інсталятор OpenCart 2.3 працює лише через
   FTP: увімкніть FTP у налаштуваннях магазину або просто скопіюйте теку `upload/` з архіву в
   корінь сайту.
2. **Увімкніть модуль.** Розширення → Модулі → Neocarts → «Встановити», потім «Редагувати».
3. **Підключіть магазин.** У панелі Neocarts відкрийте «Налаштування» → «Інтеграція». Звідти
   скопіюйте «ID магазину», «API-ключ» і «Секрет підпису» у вкладку «Підключення» плагіна.
   Натисніть «Перевірити підключення» — має з'явитися «Ключ працює».
4. **Налаштуйте вебхуки.** На тій самій вкладці плагін показує «URL вебхука». Вставте його в
   поле «URL для вебхуків» у панелі Neocarts. Без цього оплачені замовлення не з'являтимуться в
   OpenCart.

Щоб оновити плагін, завантажте нову версію поверх старої. Видаляти стару не треба: налаштування
збережуться.

## Що вміє плагін

- **Кнопка підписки** стоїть на сторінці товару, у картках каталогу й у кошику. Кожне місце
  можна вимкнути, перемістити або змінити вигляд. Для кількох популярних тем вже є готові
  налаштування.
- **Оформлення.** Якщо в кошику є хоч одна підписка, замовлення оформлюється у вікні Neocarts.
  Звичайні кошики оформлюються так, як і раніше.
- **Замовлення в OpenCart.** Кожне оплачене замовлення й кожне поновлення підписки стає
  звичайним замовленням з усіма даними покупця й доставки. Скасування й повернення коштів
  змінюють його статус.
- **Які товари.** Підписка доступна для всіх товарів одразу. Для окремого товару чи окремого
  варіанта (скажімо, розміру) її можна вимкнути. Товари, яких немає в наявності, кнопки не мають.
- **Ціни підписок** змінюються лише в панелі Neocarts. Якщо ви змінили ціну товару в OpenCart,
  діючі підписки самі не подорожчають.
- **Мови:** українська й англійська.

## Для розробників

```sh
cp .env.example .env   # дані демо-магазину; .env не потрапляє в git
make up                # OpenCart 2.3 / 3.0 / 4.1 на :8082 / :8083 / :8084, вхід admin/admin
make test              # юніт-тести на PHP 7.1 і 8.3
make e2e               # браузерні тести на всіх трьох магазинах
make build             # три архіви в dist/
```

Як влаштований проєкт і яких правил ми дотримуємось — у [`CLAUDE.md`](CLAUDE.md) і
[`docs/ai/`](docs/ai/README.md) (англійською). Як випускати нову версію —
[`docs/ai/releasing.md`](docs/ai/releasing.md). Що змінилось — [`CHANGELOG.md`](CHANGELOG.md).
